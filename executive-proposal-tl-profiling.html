Executive Project Proposal

Fitur: Tour Leader (TL) Profiling System Platform: ALVIS Backoffice & ALVIS Mobile Apps

Dokumen proposal ringkas untuk pengajuan pengembangan fitur Tour Leader Profiling di ekosistem ALVIS. Berisi gagasan utama, gambaran kerja, deliverables, dan estimasi timeline pengerjaan.

27 Agustus 2026 Backoffice + Mobile Estimasi: 4 Minggu Status: For Approval

1. Gagasan Utama (Executive Summary)

Ringkasan singkat mengenai latar belakang dan tujuan pengembangan fitur Tour Leader Profiling.

Kondisi Saat Ini

Data kualitatif Tour Leader belum terpusat dan belum terintegrasi dengan sistem ALVIS.

Solusi Digitalisasi

Sistem profiling terpusat yang memungkinkan pengumpulan data otomatis via Mobile Apps dan pemanfaatan data langsung dari Backoffice ALVIS.

Hasil yang Diharapkan

Penugasan tur (tour assignment) yang lebih tepat sasaran, berdasarkan kapabilitas TL yang terstruktur dan mudah diakses oleh tim operasional.

Fitur TL Profiling dirancang untuk mengumpulkan data kualitatif Tour Leader (seperti keahlian khusus, lisensi, penguasaan bahasa, hingga catatan kesehatan/diet) secara terstruktur. Saat ini data tersebut belum terpusat. Dengan fitur ini, pengumpulan data dilakukan secara otomatis melalui aplikasi mobile TL, sedangkan tim manajemen dan operasional dapat memantau serta memanfaatkan data tersebut langsung dari Backoffice ALVIS untuk penugasan tur (tour assignment) yang lebih tepat sasaran.

Tujuan Inti

Mendigitalisasi pengumpulan data profiling TL yang selama ini masih manual/terpisah, sehingga lebih mudah, terstruktur, dan efisien untuk kebutuhan operasional.

2. Gambaran Ringkas Gambaran Kerja (How It Works)

Berikut adalah alur kerja fitur dari dua sisi: sisi Tour Leader (Mobile App) dan sisi Admin/Operations (Backoffice Web).

Sisi Tour Leader Mobile App
  1. TL melihat banner indikator kelengkapan profil di Landing TL (Tab TL) atau di halaman Profile (contoh: "Profil 60% Lengkap").
  2. TL mengisi kuesioner singkat. Jawaban otomatis tersimpan saat TL berpindah pertanyaan.
  3. Banner selalu tampil di kedua lokasi, baik saat progres belum lengkap maupun sudah 100% (tidak auto-hide). Saat 100%, banner menampilkan status completion.
  4. TL tetap bisa memperbarui data kapan saja melalui menu Profil > Data Profiling.
  5. Data profil TL dapat diambil oleh sistem lain via Bridge API untuk kebutuhan integrasi.
Sisi Admin / Operations Backoffice Web
  1. Tim Admin/Operations mengakses halaman Tour Leaders, lalu klik tombol dropdown "Profiling Setting" di header action area untuk masuk ke halaman Manage Question atau Manage Question Group.
  2. Admin dapat membuat, mengubah, atau menonaktifkan pertanyaan kuesioner secara fleksibel tanpa perlu update aplikasi mobile.
  3. Admin juga dapat mengelelola Question Group (kategori: Keahlian, Bahasa, Lisensi, Kesehatan, Diet) untuk mengelompokkan pertanyaan.
  4. Perubahan di Backoffice langsung berlaku untuk TL di Mobile Apps.
Alur Dua Arah

Data yang diisi TL di Mobile akan tersedia real-time di Backoffice. Perubahan pertanyaan oleh Admin di Backoffice langsung berlaku untuk TL di Mobile.

3. Gambaran Output & Impact (Deliverables & Benefits)

Output sistem yang akan dihasilkan dan manfaat bisnis yang diharapkan dari pengembangan fitur ini.

Output Sistem (Deliverables)

Module Manage Question

Halaman di Backoffice untuk mengelola bank pertanyaan kuesioner (CRUD dengan tipe input Single/Multiple Choice, Short Text, Long Text, Rating Scale, branching logic, versioning, bulk import CSV) tanpa deploy aplikasi baru.

Module Manage Question Group

Halaman terpisah untuk mengelola Question Group (kategori pertanyaan: Keahlian, Bahasa, Lisensi, Kesehatan, Diet) dengan fitur drag-and-drop untuk urutan tampil.

Interactive Banner & Form Wizard

Banner progres kelengkapan di Landing TL (Tab TL) dan halaman Profile Mobile Apps, plus form wizard step-by-step dengan auto-save jawaban. Banner selalu tampil baik saat progres <100% maupun sudah 100%.

3 Tabel Database Baru

tour_tmst_tlpr_question_group, tour_tmst_tlpr_question, tour_tmst_tlpr_answer (FK ke tour_tmst_tour_leader existing), mengikuti pola schema existing tour_tmst_* dengan sys_* audit standard.

Bridge API (Read-Only)

API untuk integrasi sistem lain via bridge: GET /tour-leaders/profiling?tl_ids=.... Mengembalikan data profiling & scoring TL (1 atau banyak) dalam 1 request. Auth via X-API-Key.

tour_tmst_tlpr_question_group, tour_tmst_tlpr_question, tour_tmst_tlpr_answer (FK ke tour_tmst_tour_leader existing), mengikuti pola schema existing tour_tmst_* dengan sys_* audit standard.

Business Benefits

Data Enrichment

Database kapabilitas SDM Tour Leader menjadi terstruktur dan terpusat di dalam ALVIS.

Efficiency

Mengeliminasi proses pendataan manual atau survei terpisah yang selama ini diperlukan untuk mengumpulkan data TL.

Quality Match

Memudahkan operasional memilih TL yang paling sesuai dengan kebutuhan dan karakteristik destinasi tur.

Dampak Jangka Panjang

Data profil TL yang terstruktur dapat menjadi referensi andal bagi tim operasional dalam pengambilan keputusan penugasan tur, sehingga meningkatkan kualitas layanan dan kepuasan pelanggan.

Estimasi total durasi pengerjaan adalah 4 Minggu (1 Bulan) hingga rilis resmi.

Estimasi Total: 4 Minggu

Pengerjaan dilakukan secara paralel antara tim Backend/Backoffice dan tim Mobile Apps untuk efisiensi waktu.

Tim yang Dibutuhkan

Risiko keterlambatan jika ada perubahan requirement besar di tengah jalan. Mitigasi: BRD harus disetujui & di-freeze di akhir W1.

Catatan Persetujuan
