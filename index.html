🎯 Tujuan

Dokumentasi ini dibuat untuk mencatat dan mendokumentasikan berbagai hal penting terkait proyek yang sedang dikerjakan. Tujuan utama dari pembuatan dokumentasi ini adalah:

  • Mencatat progress — Setiap perubahan dan perkembangan proyek tercatat dengan rapi
  • Referensi — Menjadi acuan ketika diperlukan informasi teknis atau non-teknis
  • Kolaborasi — Memudahkan kolaborasi dengan anggota tim lainnya
  • Knowledge Base — Menyimpan pengetahuan yang dapat digunakan kembali di masa depan

📂 Struktur Folder

Berikut adalah struktur folder proyek ini:

📁 manual-dokumentation/ ├── 📄 index.html // Halaman utama dokumentasi ├── 📄 agent.md // Memory untuk AI Agent └── 📄 README.md // Informasi proyek

🔧 Cara Penggunaan

Untuk menjalankan dan mengelola proyek ini, ikuti langkah-langkah berikut:

  1. Clone repository — git clone https://github.com/anisareviyana/manual-dokumentation.git
  2. Buka file HTML — Buka index.html di browser untuk melihat dokumentasi
  3. Edit dokumentasi — Lakukan perubahan pada file HTML sesuai kebutuhan
  4. Push perubahan — Setiap perubahan akan otomatis di-commit dan di-push ke GitHub
